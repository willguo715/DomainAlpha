# 域名分析系统 - 定时任务调度器使用说明

## 功能说明

`scheduler.py` 是一个守护进程，会在每天上午9点自动执行域名分析任务。

## 启动方式

### 方式1：直接运行Python脚本
```bash
python scheduler.py
```

### 方式2：使用批处理文件（推荐）
双击运行 `start_scheduler.bat`，或在命令行中执行：
```bash
start_scheduler.bat
```

## 特性

1. **自动执行**：每天09:00自动执行 `main.py`
2. **日志记录**：所有执行日志保存在 `logs/` 目录下
3. **节能优化**：
   - 距离下次执行超过1小时：每小时检查一次
   - 距离下次执行超过10分钟：每10分钟检查一次
   - 距离下次执行不足10分钟：每分钟检查一次
4. **错误处理**：捕获并记录所有异常

## 日志文件

- 日志目录：`logs/`
- 日志文件名格式：`domain_analysis_YYYYMMDD_HHMMSS.log`
- 包含完整的执行输出和错误信息

## 停止调度器

按 `Ctrl+C` 可以安全停止调度器。

## 修改执行时间

编辑 `scheduler.py` 文件，找到以下行：
```python
schedule.every().day.at("09:00").do(run_domain_analysis)
```

修改 `"09:00"` 为你想要的时间，例如：
- `"08:30"` - 每天早上8:30
- `"14:00"` - 每天下午2:00
- `"09:00"` - 每天早上9:00（默认）

## 开机自启动（可选）

如果需要开机自动启动调度器，可以：

1. 创建快捷方式：右键 `start_scheduler.bat` → 创建快捷方式
2. 将快捷方式放到启动文件夹：
   - 按 `Win + R`，输入 `shell:startup`，回车
   - 将快捷方式复制到这个文件夹

## 注意事项

1. 确保Python环境已正确配置
2. 确保所有依赖包已安装（`pip install -r requirements.txt`）
3. 确保 `config.txt` 配置正确
4. 调度器需要保持运行才能执行定时任务
5. 如果电脑关机或重启，需要重新启动调度器

## 故障排查

### 问题1：调度器无法启动
- 检查Python是否正确安装
- 检查是否在项目根目录运行

### 问题2：任务没有执行
- 检查调度器是否正在运行
- 检查系统时间是否正确
- 查看日志文件了解详细错误信息

### 问题3：任务执行失败
- 查看 `logs/` 目录下的日志文件
- 检查网络连接
- 检查配置文件是否正确
